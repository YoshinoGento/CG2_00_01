# 畑の保存・履歴の確認手順

## 今回の変更

- 作物の成長・乾燥で実際に値が変わると、畑が「未保存」になる。
- ImGuiを使わない構成のキーボードUndo/Redoでも、未保存表示と灌漑情報を更新する。
- 水やり量や成長速度、保存ファイルの形式は変更していない。

## 動画で確認する操作

既存の大切な畑を上書きしないよう、まず「名前を付けて保存」で確認用の別名を作る。
数値の前後を比較するときは、上部の一時停止を使い、自動成長や給水を止める。

1. 開発モードで同じ畑マスを選択し、マス番号・水分・高さを映す。
2. 耕したマスに水やりし、水分が10ポイント増えるところを映す。
3. 上部の「元に戻す」で水分が戻り、「やり直す」で再び増えるところを映す。操作履歴の件数も映す。
4. 一時停止中に保存する。保存名と「保存済み」、選択マスの数値を映す。
5. 水やりや高さ変更で別の状態にし、「未保存」に変わるところを映す。
6. セーブ一覧から同じ保存名を読み込む。未保存変更の破棄確認が出たら、確認用データであることを確認して進める。
7. 保存時の水分・高さ・作物に戻ったことと、古いUndo/Redo履歴が残っていないことを映す。
8. 成長中の作物を含む畑を保存し、再生する。成長度や水分の変化とともに「未保存」に変わることを映す。
9. 必要な状態を保存してゲームを終了し、起動し直す。保存名、用水路・水源・貯水量、所持金、種、選択作物を比較する。

起動後は自動給水・成長が再開するため、比較する数値は早めに一時停止して確認する。
再起動の証拠は、終了から起動までを画面全体の録画で残すか、前後の動画を対にする。

## 保存範囲と未検証事項

- 保存対象: 20マスの地形・作物・水分・成長・貯水量、選択マス、所持金、収穫物、種、選択作物など。
- 日付、プレイヤー位置、Undo/Redo履歴自体の永続化は今回の保存対象ではない。
- 自動テストで保存/読込、新規Systemインスタンスでの再読込、旧形式の読込、不正データの拒否を確認した。
- この手順による実ゲームの再起動・画面上の操作確認は未実施。自動テストの合格を動画での実証と同一扱いにしない。
- 週間報告は保留中。点数は今週の計画と動画で確認できた成果をもとに評価し、今回の修正だけで特定の点数を保証しない。
