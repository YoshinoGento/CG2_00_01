# 畑の配置ライブラリ

## 進行セーブとの違い

既存のImGuiセーブ・ロードは変更せず残している。配置ライブラリは別のSystem・形式・フォルダーを使い、進行セーブの一覧には混ぜない。

| 項目 | 配置記録 |
| --- | --- |
| マス数・高さ | 保存する。同じマス数の農場へ適用する |
| 耕した区画 | 保存する。植付け済みの区画も耕した区画として記録 |
| 用水路・水源 | 保存する |
| 植わっている作物・成長度・水分 | 保存しない。配置適用時に消去 |
| 水路の貯水量 | 保存しない。水源は満水、水路は空から既存の水処理を開始 |
| 所持金・種・収穫物・日数・クリア状態 | 配置適用では変更しない |

作物も含めて途中から再開したい場合は、従来の進行セーブを使う。配置適用は新規ゲーム開始ではないため、クリア状態も自動解除しない。

## 操作

1. Debug／Developmentでは上部の「配置ライブラリ...」。Releaseでは農場メニュー→セーブ・ロード→「配置だけを保存・再現」。
2. 名前を入力し「この名前で配置を保存」。日本語入力対応。同名の記録は上書きせず拒否する。
3. 一覧から名前を選び「選んだ配置を適用...」。確認後、現在の畑全体を置き換える。

適用前に、植わっている作物が消えることを確認する。編集履歴・プレビュー・生育比較・巻戻し履歴も古い畑を参照しないようクリアする。適用後は進行セーブを「未保存」にするが、既存ファイルを自動上書きしない。

プレビュー中はライブラリを開けない。先に確定またはキャンセルする。

## 名前の入力と表示

Releaseの「新しい記録として保存」も自動日時名ではなく名前入力を開く。「現在の保存名」「選択中の保存名」をゲーム内に表示する。長い名前は末尾を省略し、名前付きの選択一覧では横スクロールで確認できる。

入力・一覧はWindows標準ダイアログで、ImGuiは使用しない。ゲーム描画を停止した状態で日本語IMEを利用する。名前の入力上限はUTF-16で64コード単位、UTF-8で192バイト。配置名の前後の半角空白・制御文字は不可。

## 保存場所と安全性

- 配置: `project/Settings/farm_layouts/layout_*.json`。名前をファイルパスとして使わない。
- 既存の進行セーブ: `project/Settings/farm/`。従来どおり。
- 配置は最大256件、1ファイル1MiB以内、幅・高さ128以下。版・種類・マス数・高さ・機能値を検証してから畑を変更する。
- 保存は一時ファイルを閉じた後にリネームする。書込み失敗時に既存記録を上書きしない。複数ゲームプロセスからの同時保存は検証対象外。
- 破損した配置は一覧から除外する。読み込み時にも再検証し、不正な場合は現在の畑を維持する。

## 検証

配置の日本語名往復、高さ・区画・水源・水路の再現、作物・成長・水分の除外、選択マス保持、同名拒否、破損JSON・異なるマス数・範囲外値・不正ID拒否を専用CPUテストで確認した。従来の保存／履歴テストも合格。

Debug／Development／Release x64ビルド成功。両ビルドの配置画面・キャンセル、Releaseの保存名の画面内表示と日本語名への切替を実機確認。Debugでは日本語の配置名を入力して保存し、一覧への反映とJSONを確認した。確認専用の配置記録は削除済み。配置の保存→適用を両ビルドの実画面で最後まで操作する確認は残っている。
