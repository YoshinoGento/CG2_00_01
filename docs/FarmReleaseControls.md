# Release版の農場操作

対象: 個人就職作品の農業ゲーム。ImGuiの開発画面ではなく、Sprite描画の日本語メニューを使う。

## 起動

Visual StudioでCG2_00_01をスタートアッププロジェクトにし、Release / x64で起動する。作業ディレクトリはproject。EXEだけの単体配布ではResources、Settings、Shader、DLLなどの依存物が不足するため、今回の変更は配布パッケージ完成を意味しない。

## 基本操作

### 大会に向けた給水と育成の注意（9/14確認）

水路は隣の畑と同じ高さ以上に置く。例えばニンジンの畑をH1にした場合、H0の水路からは給水されない。水源から水路へも上り坂には水が流れないため、経路の高低差と接続状態を確認する。

常時給水は高品質を保証しない。水分過多の表示が出たら、水源・水路の配置と現在の水分を確認する。じょうろは1回ずつ水分を増やすので、満タンにすることだけを目標にしない。

既定ルールの36ケースを自動検証した結果と制約は [30日間のバランス検証](testing/FarmSeasonBalance_20260914.md) を参照。今回は操作やゲームの数値を変更していない。

### 最終結果の大会評価（9/14追加）

大会終了時の結果画面に「大会評価（仮）」と「次の評価まで」を表示する。保存済みの終了した農場を開いた場合にも、提出結果から評価を再計算する。結果画面の保存・農場閲覧・再開始は従来どおり。

- 3大会の合計300点を基準に、S：270点以上、A：240点以上、B：180点以上、C：120点以上、D：120点未満。
- 1度も提出していない場合は「出場なし」で評価は `--`。提出して0点だった場合はD。進行中や不正な結果は評価しない。
- 例：合計37点ならD、「次の評価まで C / 83 pt」。最高のSと評価なしでは、次の評価の欄は `--`。
- 次の評価までの点差は次回プレイの目安であり、終了した大会へ追加提出できるという意味ではない。
- これは大会得点だけの仮基準。農場ランク・他プレイヤーとの順位・賞金とは別で、売上や虫被害は採点しない。
- Debug／Developmentの畑Inspector「大会の提出結果」でも評価・点差・全基準を確認できる。

基準の難易度は30日間の通しプレイ後に調整する。現時点で高評価の到達しやすさまで検証済みとはしない。

### 体験版と30日間の大会モード（9/14追加）

- 新しい農場は「３０日間の大会」で開始する。540Gに達しても終了せず、10・20・30日目の大会へ進める。
- 以前の通常セーブ（schema1～13）は「５４０Ｇの体験版」として読み込む。開始・体験版クリア画面の切替ボタン、または「農場メニュー → 時間・カメラ」から大会モードへ切り替えられる。
- 切替は確認してから実行する。畑・日付・作物・所持金を保持するが、Undo／Redoと時点復元履歴は初期化する。日付は戻らないため、31日目以降の農場を大会モードにすると終了状態になる。
- 大会モードは30日目の提出完了、または31日目の開始で時間と農作業を止め、自動で最終結果を開く。提出数・未出場数・得点を表示するが、順位・賞金はまだない。
- 結果画面から「セーブ・ロード」で通常保存、「終了した農場を見る」で閲覧、「農場を最初からやり直す」で再開始できる。再開始は現在のモードを保持する。
- 通常保存はschema14でモードも記録する。自動保存ではないので、切替後や大会終了後に手動で保存する。配置だけの保存とは別。schema14を以前のEXEへ読み込ませることはできない。
- Debug／Developmentでは畑Inspectorにもモード切替と同じ進行率を表示する。

### 大会の途中集計・最終集計（9/14追加）

「農場メニュー → 農作業・売買 → 収穫物の保管庫 → 審査プレビュー → 大会の対象期間 → 大会の提出結果」で確認できる。予約品がなくても結果は開ける。

- 開催前：まだ大会日になっていない。未出場には数えない。
- 受付中：10・20・30日目の当日で、まだ提出していない。当日中は既存の提出操作が使える。
- 提出済み：作物名、品質点、大きさ点、合計、収穫日・サイズを表示する。
- 未出場：当日を過ぎても提出記録がない。得点欄は `--`。提出して0点だった結果とは区別する。
- 下段に提出数・未出場数・提出済みの総得点を表示する。30日目の提出後、または31日目以降は「３０日間の大会結果」になる。最大3大会・300点。順位や賞金ではない。

日付と提出結果を通常セーブで保存すれば、ロード時も同じ基準で集計する。配置保存には含めない。Debug／DevelopmentのInspector「大会の提出結果」にも同じ判定・集計を表示する。

大会モードの自動画面遷移・時間停止は上記の仕様で実装済み。体験版の540G条件は残し、順位・賞金は未実装。

### 大会当日の自動停止（9/14追加）

未提出の10・20・30日目になると時間が止まり、日本語の大会案内が開く。1倍・2倍・4倍速でも同じ。

- 「出品画面へ（停止を維持）」：対象期間と予約品を確認する画面へ直接移動する。確認して提出後も、農場へ戻るまではメニューで停止する。戻った後も明示的な停止を維持するので、再開は「時間を進める」を押す。
- 「畑で準備（停止を維持）」：日付・成長・給水を止めたまま、植付けや収穫などの手動操作を続けられる。成長させたい場合は「時間を進める」で再開する。
- 「案内を閉じて時間を進める」：案内を確認済みにして再開する。当日を過ぎるとその大会には提出できない。自動提出や遅れ提出は行わない。

同じプレイ中は確認済みの大会案内を繰り返さない。未提出の当日セーブをロードした場合は再び案内する。提出済み大会では停止しない。過去へ時間を巻き戻した場合はその時点の結果から再判定する。案内の確認状態は保存せず、通常Save schema13と配置保存は変更しない。

Debug／Developmentは畑Inspectorに「○日目の大会：時間を停止中」を表示する。停止中に保管庫から提出するか、「大会案内を閉じて時間を進める」を押す。既存のEditor一時停止を自動解除する機能ではない。

### 大会へ１個を提出する（9/14追加・現行仕様）

1. 収穫物の保管庫で、サイズが記録された野菜を１個保護し、出品予約する。
2. 農場の10・20・30日目に「予約した野菜の審査プレビュー → 大会の対象期間」を開く。
3. 対象期間内なら「予約した１個を提出」を押し、確認画面で確定する。キャンセルでは消費しない。
4. 「大会の提出結果」で品質点・大きさ点・合計と収穫日・サイズを確認する。
5. 終了前に「セーブ・ロード → 現在の農場を上書き保存」または新規保存を行う。自動保存ではない。

提出成功時は在庫から１個を消費し、予約を解除する。各大会は１回だけで、Undoと時間巻き戻しの履歴をその時点で区切る。結果は通常セーブschema13に保存し、配置専用保存には含めない。提出後のセーブを再起動しても同じ大会へ再提出できない。提出前の古いセーブをロードすれば、その時点の農場に戻る。

大会当日以外・対象期間外・収穫日不明・未予約では提出不可。日付を飛ばしても自動提出や遅れ提出は行わない。記録する得点は現行V1の品質60点＋大きさ40点。順位・賞金・大会日の自動停止・30日最終結果は未実装で、540G体験版目標は別に維持する。この節は下記の旧追補にある「提出未実装」を更新する。

Debug／DevelopmentはImGuiの「収穫物の保管庫 → 予約した１個を提出」で確認後に同じ処理を実行し、「大会の提出結果」で記録を確認できる。

### 大会の対象期間を調べる（9/14追加）

「農場メニュー → 農作業・売買 → 収穫物の保管庫 → 予約した野菜の審査プレビュー → 大会の対象期間」で確認する。現在の農場日、対象大会日、収穫日の範囲、残り日数、予約した野菜の収穫日、対象外の理由を表示する。「収穫物の保管庫」で予約を選び直し、「採点の試算へ」で得点の内訳に戻れる。

- 10日大会：1～10日収穫。20日大会：11～20日収穫。30日大会：21～30日収穫。各期間は両端を含む仮ルール。
- 13日目に10日収穫の野菜を予約している場合、次の20日大会には対象期間外。12日収穫の野菜なら対象期間内。
- 収穫日不明の旧記録、未来日付、不正記録は対象内と扱わない。31日以降は対象大会なし。当日の残り日数は0。
- 期間を見るだけでは予約や在庫を変更しない。提出ボタンの確認後だけ１個を消費する。対象期間外でも保護・予約は維持する。

Debug／DevelopmentのImGuiでは「収穫物の保管庫」内の「大会の対象期間（仮ルール）」を開く。Releaseと同じSystemの結果を表示する。

### 購入・収穫の通知（9/14調整）

通常プレイ中の通知は、画面上部中央の「地形・用水路」「時間を止める」の下に表示する。通知中だけ、同じ場所のサイズ予測・保護中の個数・出品予約を一時的に隠し、通知が消えると現在の情報を再表示する。保護や予約そのものは解除しない。

所持金、日付、農具、右側の実行ボタンは残る。通知枠をクリックしても背後の畑は選択・操作されない。収穫通知の品質点・売価、購入した種の名前は従来の内容を維持する。

### 時間を止めて比較用の畑を準備する（9/14調整）

「時間を止める」は日付・成長・給水・プレイヤー移動を止める。通常の農作業画面では、停止中もマスのクリック選択、道具ボタン、右側の実行ボタンを使える。種は通常どおり消費し、水やりも通常の量だけ増える。メニューや観察パネルの背後の畑には操作を通さない。

1. 同じ作物の種を2個用意し、時間を止める。
2. 同じ高さの2マスを順に選び、耕して種を植える。止めたままなので両方の開始成長度を0%にそろえられる。
3. 比較したい水分を調整する。水分だけを比較するなら、養分と自動給水条件もそろえる。
4. 「農場メニュー → 観察ノート → 選択マスを観察Aに登録」。プレイ画面で他方をBに選び、「生育比較を開始」を押すと時間が進む。
5. 両方の収穫時刻が出たら結果を確認する。「比較記録をリセット」で選択と測定をやり直せる。

停止中のキーボード入力も既存FarmInputSystemへ渡す。矢印、1～4、Q/E、Enter、B、V/Fが対象。Cの作物ホイールは停止中には開かず、作物変更は既存メニューを使う。クリア後の農作業禁止、観察中の通常農作業禁止は維持する。時間停止中の収穫演出は、時間を再開してから進む。

### 収穫日と農場の時間（9/12追加）

「農場メニュー → 農作業・売買 → 収穫物の保管庫」で、各収穫物の「収穫日」を確認できる。例えば「収穫日 4」は4日目に収穫した記録。ImGuiの保管庫にも同じ日付を表示する。Undoで収穫を戻してからRedoしても、最初に収穫した日付を保つ。

通常のセーブ・ロードは、収穫日とともに農場の日付・その日の日内経過時間・時間倍率を保存復元する。時間を進めるだけでも未保存になる。「配置だけを保存・再現」は従来どおり別機能で、時計や収穫物を保存しない。

旧セーブには収穫日・時計の情報がないため、個別の収穫記録は「収穫日不明」、農場の時計は1日目・日内0秒・通常速度で読み込む。過去の日付を推測して付けない。大会の対象期間判定・当日の提出・順位・賞金はまだ未実装で、今回の収穫日はそのための記録基盤。

### 植えている野菜の見た目（9/12調整）

ニンジンは根の約84％を地中に埋め、オレンジ色の肩と葉を地上に出す。カブは根の下半分を埋め、上半分と葉を見せる。葉は根の上端付近につなぎ、幼苗は土面から芽を出す。畑の高さ・成長段階・サイズ倍率に追従し、操作の追加はない。坂はマス境界にあり、植える位置は中央の平らな土面を使う。

品質・売価・成長・セーブは変わらない。OBJ欠落時のデバッグ線の代替表示は従来のまま。

### 収穫時の引き抜き演出（9/12追加）

収穫可能なマスを選び、「4 収穫」→「収穫する」、または収穫道具でEnterを押す。追加の操作は不要。ニンジンとカブが0.3秒で土から持ち上がり、根全体を0.9秒見せた後、0.4秒かけて小さくなって消える。サイズは収穫直前の表示を引き継ぐ。

保管庫には収穫成功時点で1個だけ追加される。演出の終了を待つ必要はなく、失敗した収穫では演出しない。通知は畑を隠しにくい上部中央へ移した。時間停止・メニュー表示中は演出も停止し、ロードややり直し、Undo/Redoでは古い演出を残さない。最大8個を同時表示し、それ以上は古い演出から置き換える。

ImGuiでは「収穫物の保管庫」の「引き抜き演出中」で表示中の個数を確認できる。これは一時的な見た目の数で、所持数ではない。OBJが使えない場合の線描画には引き抜き演出を追加していない。

### 出品予約の審査プレビュー（9/12追加）

1. 「農場メニュー → 農作業・売買 → 収穫物の保管庫」で野菜を保護し、1個を出品予約する。
2. 下の「予約した野菜の審査プレビュー」を押す。記録された品質・サイズと、それぞれの配点、合計点を確認できる。
3. 「収穫物の保管庫」で戻り、別の野菜を予約すれば試算対象も変わる。「農場に戻る」でプレイを再開する。メニュー表示中は農作業と時間を停止する。

仮ルールは品質60点・大きさ40点。品質点を60%に換算し、サイズは0.5倍を0点、2.0倍を40点として直線的に換算する。範囲外は上下限へ制限し、各得点を四捨五入してから合計する。例：品質93・1.46倍なら56＋26＝82点。売価・作物の絶対寸法は使わず、保存済みの品質点と種類内の相対サイズを使う。養分履歴が不足する古い記録は、その旨を表示し保存済み品質点で試算する。

これは最終大会の成績ではない。提出確定、日付制限、順位、賞金、作物の消費はまだ行わず、所持金540Gの目標も変更しない。試算値は保存せず、その時点の予約から再計算する。ImGuiでは「収穫物の保管庫 → 審査プレビュー（仮ルール）」で同じ内訳を確認する。

### 大会に残す1個の出品予約（9/12追加）

- 「農場メニュー → 農作業・売買 → 収穫物の保管庫」を開き、残す野菜を「保護する」。その行の「この1個を出品予約」で予約する。保管庫は読みやすさを優先して2件ずつ表示する。
- 予約できるのは、保護済み・個数1・収穫サイズの記録がある行。個別詳細のない旧在庫、サイズ不明、複数個をまとめた記録は対象外。通常の新しい収穫は1個ずつ記録される。
- 同時に予約できるのは1個。別の対象行を予約すると入れ替わり、元の野菜の保護は残る。「出品予約中・取消」を押すと予約だけを解除する。予約中の野菜を売るには、予約取消→保護解除の順で操作する。
- 予約作物名は保管庫上部と通常のプレイHUDに表示する。予約行は色だけでなく「出品予約中・取消」と表示し、保護解除を無効にする。ページが変わっても予約は保持する。ImGuiの保管庫表にも出品予約チェックと予約IDを表示し、横スクロールで列を確認できる。
- 通常Saveはschema11で予約を保存し、旧schema1～10は予約なしで扱う。配置専用Saveとは別。変更成功時に以前の編集Undo履歴を確定する。古いセーブや時間巻き戻しでは、予約状態もその時点へ戻る。
- これは大会候補を1個に絞る準備段階。上記の試算はできるが、大会への提出確定、日付による締切、正式採点、報酬、作物の消費はまだ行わない。所持金540Gの体験版目標は変更していない。

### 収穫物の保管庫（9/11追加）

- 作物を収穫した後、「農場メニュー → 農作業・売買 → 収穫物の保管庫」で確認する。2件ずつ表示し、「前のページ／次のページ」で移動する。表示中は時間と農作業を停止する。
- 収穫ごとの作物名、個数、収穫時のサイズ倍率、品質点、確定単価を保持する。通常操作は1回の収穫で1件。値が不明なサイズは `--`。
- 各行の「保護する」を押すと「保護中」になり、その収穫物を売却から除外する。再度押すと解除する。通常は1行1個で、まとめて記録された行はその個数すべてが対象。保護操作では出品や採点は行わない。
- 「選択中の作物を売る」は同じ種類の未保護分、「全売却」は全種類の未保護分だけを売る。売却予定額も保護分を除く。成功すると売った記録だけが消え、保護した記録と確定品質・サイズは残る。全件保護中は売却できない。「直前の収穫結果」は履歴なので売却後も残る。個別1件の売却・出品はまだない。
- プレイ画面には保護中の個数を表示する。保護の変更は通常セーブで保存されるが、自動保存ではない。配置専用の記録には含めない。
- 保管できる記録は128件。満杯なら収穫を拒否し、畑の作物は残す。売却で空きを作れる。古いセーブの合計所持数と売却額は保持し、個別情報のない分を「詳細不明の収穫物」と表示する。最後の品質を他の収穫物へ流用しない。
- 通常のセーブ・ロードで保管庫も保存する。schema10は保護フラグと記録IDを保持し、schema9は未保護の記録へ移行する。詳細不明の旧在庫は個別に保護できない。収穫のUndo/Redoにも連動し、売却後と保護変更後はそれ以前の編集履歴を確定する。ImGuiの畑Inspectorの「収穫物の保管庫」でも「売却保護」を切り替えられる。地形プレビュー・時間巻き戻し中は保護を変更できない。
- 大会候補は売らずに残した作物から選ぶ方針。この段階は記録の基盤であり、30日目の大会への出品・採点は未実装。
- 保護は「売却から除外する」設定。古い通常セーブをロードしたり、時間巻き戻しで過去の農場へ戻した場合は、保護状態もその時点へ戻る。過去のセーブまで書き換える機能ではない。

### 畑を見ながら地形・用水路を操作（9/10追加）

高さをまとめて変更する操作（9/11追加）：始点を選び「土地を高くする／低くする」を押す。その後、左ボタンを押したまま畑をなぞると変更候補が増える。離れた位置へ高速移動した場合は直線上のマスを補間する。マウスを離すか、操作パネル上・畑の外へ出ると線を区切り、別の場所から追加できる。

1. 開始マスを選ぶ。
2. 地形・用水路から「用水路をつなげる」を選ぶ。
3. 地面上を左ボタンでドラッグする。既存の経路プレビューで変更候補を確認する。
4. 「この変更を確定」を押す。やめる場合はキャンセルする。

撤去も「用水路をまとめて撤去」から同様に操作する。古い世代の畑に対する確定や、Systemが禁止する配置は実行しない。プレビュー中は実際の畑へ書き込まない。

## 記録・観察・撮影

- セーブ・ロード: 上書き保存／名前を入力して新規保存、前後の記録選択、名前付き一覧から読込。現在・選択中の保存名をゲーム内に表示する。既存の名前変更・削除はReleaseメニューの対象外。
- 配置だけを保存・再現: 進行セーブとは独立した[配置ライブラリ](FarmLayoutPresets.md)。高さ・耕した区画・用水路・水源を記録する。適用すると植わっている作物は消えるため確認が必要。
- 読込・最初から・終了: 未保存変更を失うため確認画面を挟む。読込後は古い比較記録とタイムラインをリセットする。
- 観察ノート: 選択マスをA/Bに登録し、同じ作物・高さ・成長度など既存Systemの比較条件を満たしてから開始。成熟・水分・地形の行と養分充足度の行、品質点、予想単価、水分・成長を表示する。
- 時間・カメラ: 停止／再開、1倍／2倍／4倍、プレイヤー追従／農場を見渡す。
- 録画例: 通常速度で種購入→作物選択→耕作・植付け→地形と用水路のプレビュー・確定→生育比較→収穫・販売。編集中のメニュー画面と通常のHUD画面を両方含める。

### 育成中の水分履歴と品質（9/10追加）

- 作物が成長している間、乾燥・水不足・適量・水過多だった時間と、その期間の成長効率を畑マスごとに記録する。単に収穫直前だけ水分を整えても、長く続いた悪条件は消えない。
- 収穫時の品質点に含まれる「水分バランス」は、履歴がある場合は育成期間の平均成長効率から計算する。農場メニューの観察ノートで4項目の品質評価・品質点・予想売価を確認でき、収穫時は通常HUDの品質点と価格へ反映される。
- Debug/Developmentでは畑Inspectorの「育成中の水分履歴」に、記録秒、4状態の割合、期間平均の成長効率を表示する。ここは確認表示だけで、ImGuiから履歴を書き換えない。
- 履歴は進行セーブ、Load、Undo/Redo、Timelineに含まれる。旧Save Version 1～5は履歴なしで読み込み、以後に時間を進めた分から記録する。植付けで初期化し、収穫後は次の作物へ持ち越さない。
- 作物を選ぶとプレイ画面上部に「サイズ予測（基準比）」を表示。農場メニューの品質画面では現在の作物と直近の収穫を切り替え、予測値と確定した収穫サイズを確認できます。ImGui Inspectorにも同じ数値を表示します。
- 1.00xはその作物の基準サイズ。水分による平均成長効率と養分充足度の育成履歴から、現在は0.50～2.00xの収穫サイズを予測します。育て方で予測は変動し、収穫で固定されます。現在のモデルの寸法・重量ではありません。
- 履歴のない植付け直後や旧セーブの収穫記録は「--」。サイズのためだけに直前に水や堆肥を足しても過去の履歴は変わりません。売価は既存品質計算のままです。
- カブは丸い淡色の根、ニンジンは先細りのオレンジ色の根を持つ立体OBJ表示です。植付け後は葉が表示され、収穫に近づくと根も表示されます。既存の操作で育てるだけで切り替わり、収穫すると消えます。
- 成長度に応じてサイズ予測を根・葉へ反映します。根元の位置は維持し、表示幅を制限します。画面の倍率は成長度と表示幅制限を含むため、収穫記録値そのものではありません。モデル欠落時は従来の線表示になります。
- 大会点・全収穫物のサイズ一覧は未実装。現段階は直近1件の収穫サイズを保存します。品質レーダーは養分充足度を加えた4項目で、サイズとは別表示です。

### 土づくり・養分（9/10追加）

- 畑を選んで耕し、「農場メニュー → 農作業・売買 → 土づくり・養分を確認」へ進む。植付け前は選択中の種、植付け後はそのマスの作物を表示する。
- 「堆肥を混ぜる（無料）」で養分を100に補う。植付け前の耕作済み土だけで使える。満タン・作物あり・水路・水源では実行不可。現在は無料の試作ルールで、肥料購入や費用は未実装。
- カブの目安45・成長0～100%の消費30、ニンジンの目安65・消費45。ゲーム用の抽象値で、実在の栄養素量ではない。初期養分60。目安以上では不足なし、成長で消費するため事前準備に意味がある。過剰養分のペナルティはない。
- 養分不足は品質と売価に作用し、成長速度は既存の水分条件で決まる。収穫後も土の残量を維持する。次の植付け前に再び補える。
- Debug Inspectorに4軸レーダー・数値・堆肥ボタン、Releaseの土づくりと観察ノートに養分評価を表示。メニュー中は既存の時間停止を維持。堆肥はUndo/Redo対応。
- 通常セーブschema7に養分と履歴を保存。配置だけの保存には含めない。schema1～6は初期養分60・養分履歴なしとして移行。旧収穫済み作物の点数・価格は維持し、生育中で養分履歴がない場合は現在の養分を暫定評価に使う。

## 畑を見ながら観察する（追加）

従来の観察ノートはそのまま使用できる。追加パネルはReleaseのSprite UIであり、ImGuiではない。Debug/Developmentの既存観察UIは変更していない。

1. 畑でマスを選び、農場メニュー → 観察ノート → 「選択マスを観察Ａに登録」。Ｂからでも開始できる。
2. メニューが閉じ、観察専用パネルを表示して時間を止める。もう片方が未登録ならその選択待ちになる。畑をクリックすると直接登録する。方向キーで選び、Enterでも登録できる。
3. Ａ／Ｂ両方を登録したら、比較条件を確認して「生育比較を開始」。時間が進み、水分・成長・計測時間を同じ画面で確認できる。
4. 「時間を止める／進める」と1・2・4倍速を利用する。停止中でも選択・登録は可能。「Ａ／Ｂのマスを選択」は登録を変えず選択枠だけを移す。
5. 「比較を終了」で結果を保持し、観察中の時間も停止する。両方が収穫可能になった場合や計測が無効になった場合も、観察画面では自動停止する。
6. 「農作業に戻る」で通常HUDと操作へ戻る。時間停止設定は観察に入る前の状態へ戻す。比較そのものの終了は「比較を終了」で行う。

- 「Ａ／Ｂを選び直す」で再び畑から登録できる。選択待ちだけの取消はキャンセル・右クリック・Esc。登録済みの記録は取り消さない。
- Ａ／Ｂは観察枠の名前であり、キーボードのA/Bではない。観察中のWASD移動・B購入・道具操作は遮断し、選択操作で農場を変えない。
- 「収穫秒」は比較開始から収穫可能に到達したゲーム内経過秒。残り時間の予測ではない。未到達は `--`。2倍速なら実時間より2倍速く計測秒が進む。
- 終了後の水分・成長・収穫秒は計測終了時の記録。無効表示の場合は正しい比較として扱わず、リセットして登録し直す。
- 比較には異なる2マス、成長途中の同じ作物、同じ高さと成長度などが必要。時間停止は既存の成長差を揃える機能ではない。差があれば同時期に植えたマスを用意する。
- 観察中は通常HUDを一時的に隠し、パネルの重複を避ける。観察ノートボタンから従来の品質詳細に戻れる。農作業・地形・記録タブへ移動すると観察専用操作を抜ける。
- ユーザー提供の16:05:24画像では、Ａ登録後のプレイ画面、Ｂ選択待ち、一時停止、Ａの水分・成長表示を確認した。下端のボタンが画面端に寄っていたため16px上へ調整。「農場を見渡す」は観察パネルを避ける専用の距離・位置へ調整した。修正後の実機操作、比較開始から完了までの通し確認は未完了。CPUテストと実操作確認は区別する。

## 検証の注意

開発用の全ImGui項目をReleaseへ移したわけではない。Particle、PostEffect、モデル調整、エンジン診断は開発側に残す。ゲームパッド専用のメニューフォーカスとキー割当変更も今回の対象外。ビルド確認と実際の操作確認を区別し、最終結果は作業記録に記載する。

### 2026-09-09の確認結果

- Debug／Development／Release x64のビルド成功。
- CPUテスト: メニューの当たり判定・無効項目・移動・範囲外入力、生育比較、水分データ保存、保存履歴・Undo／Redoが合格。
- 実機: 1280×720と1920×1080で表示とクリック位置を確認。5タブ、道具選択、畑選択、俯瞰カメラ、高さプレビューと取消、読込確認と取消を確認。
- 実機の売買: 収穫物3個→0個、所持金20G→461G。続く種購入で所持金421G、種4個→5個。セーブを実行せず検証用ゲームを終了した。
