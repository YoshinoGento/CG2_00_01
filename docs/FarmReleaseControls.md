# Release版の農場操作

対象: 個人就職作品の農業ゲーム。ImGuiの開発画面ではなく、Sprite描画の日本語メニューを使う。

## 起動

Visual StudioでCG2_00_01をスタートアッププロジェクトにし、Release / x64で起動する。作業ディレクトリはproject。EXEだけの単体配布ではResources、Settings、Shader、DLLなどの依存物が不足するため、今回の変更は配布パッケージ完成を意味しない。

## 基本操作

### 畑を見ながら地形・用水路を操作（9/10追加）

- プレイ画面上部の「地形・用水路」で専用の操作バーへ切り替える。既存メニューはそのまま残し、そちらの「農場を見渡す」からも入れる。
- 畑をクリック、または方向キーで選択。「土地を高くする／低くする」「用水路」「水源」で変更をプレビューし、「この変更を確定」で反映する。確定後も操作バーに残るため、続けて次のマスを選べる。
- 「用水路をつなげる／まとめて撤去」は選択マスを始点にする。その後、畑の上で左ボタンを押して経路を延ばし、確定する。ボタンやパネルの上では経路を伸ばさない。経路の設置条件は従来どおり。
- Enterは確定、右クリックまたはEscは未確定変更の取消。プレビューがない状態のEsc、または「農場に戻る」で農作業へ戻る。戻る際に未確定の変更は破棄され、確定済みの変更は残る。
- 「元に戻す／やり直す」もその場で操作可能。「堆肥を混ぜる」は既存の条件を満たす未植付けの土だけで使える。
- 地形作業中は時間と通常の農作業入力を止める。終了後は入る前の一時停止設定に戻り、手動で止めていた時間を勝手に再開しない。
- 通常のプレイ画面にも「時間を止める／進める」を追加。速度設定、詳細な品質や記録管理などは従来メニューに残す。表示はImGuiではなく既存のSprite UI。

### 作物の品質レーダー（9/10追加）

- 畑のマスを選び「農場メニュー→農作業・売買→作物の品質を見る」。「土づくり」画面からも開ける。
- 「選択マスの品質予測」は、そのマスの作物名、マス番号、収穫前の品質点と予想単価を表示する。
- 「直前の収穫結果」は最後に収穫した1個の品質点と確定単価。選択中の種やマスと別の記録であり、過去の全収穫一覧ではない。
- 1:成熟、2:水分バランス、3:地形適性、4:養分充足度。外周100、1目盛25。日本語の数値欄を併記し、形や色だけに依存しない。
- 値のない軸は `--` として接続線を描かない。古い記録の養分を0点や100点と推測しない。未植付けと未収穫はそれぞれデータなし表示。
- 図の下に栽培ヒントを追加。整数表示した既知の項目で最も低い値を案内し、同値なら成熟→水分→地形→養分の順。不明な項目は除外する。売価への影響が最大の項目を示すものではない。
- 成熟は成長100%まで待つ、水分は育成中の不足・過多を避ける、地形と養分は次の植付け前の準備を案内する。低い水分評価だけから現在の水不足と断定せず、追加の水やりを自動実行しない。
- 全項目が表示上100なら良好と表示。不明な項目がある場合は部分的な評価と明示する。ヒントは品質点・売価・畑データを変更しない。Debugの品質欄にも同じ判定と最低値を表示する。

### 起動と目標達成（9/9追加）

- 起動時は体験版の目標確認画面で時間が止まる。「この農場でプレイする」で現在の農場を継続する。既存セーブを消したり、新規データへ自動で置き換えたりしない。
- 現在の目標は所持金（既定540G）。30日目のコンテストは未実装であり、この体験版の目標とは別。
- 「農場を最初からやり直す」は破棄確認を挟んでから初期化し、目標確認へ戻る。保存ファイルは自動上書きしない。
- 達成後の結果は一度だけ表示する。「達成した農場を見る」で戻れるが、クリア済みの農作業制限は従来どおり。再挑戦は初期化を選ぶ。
- Releaseで結果から農場へ戻った際は、旧STAGE CLEAR文字を重ねず畑を確認できる。
- Releaseで結果から農場へ戻った際は、旧STAGE CLEAR文字を重ねず畑を確認できる。
- 開始画面・結果画面から「セーブ・ロード」を開ける。読込成功後は読み込んだ農場の目標確認、またはクリア済み結果を表示する。
- 起動・達成・再挑戦の通し動作はCPUで検証。実画面では保存済み農場からの起動、植付け・成長・収穫・販売・結果・農場へ戻るまでを確認。新規農場からの通しプレイと再挑戦は別途必要。

### マウスで農作業する（9/9追加）

選択したマスには黄色の立体的な四隅を表示する。右下の「選択中」の番号と左下の選択マス番号を照合してから実行する。黄色は「選択中」の意味であり、作業可能という意味ではない。実行可否は理由表示とボタンの有効・無効で確認する。カーソルを動かすだけでは選択も農作業も行わない。

枠は既存OBJによる描画で、通常のゲーム表示では選択用デバッグ線を重ねない。未耕作・耕作済み・用水路・水源に対応し、高さに追従する。地形プレビューのオレンジ線と開発表示のガイドは保持する。通常の奥行き判定を使うため、大きな作物などに遮られる場合は「農場を見渡す」で確認する。

確認済み: Releaseで0→19→8の選択と番号同期、19だけを耕作、水源8の配置・H0→H1変更、1280x720と1920x1080の表示。CPUで混在高さ243パターン、無効番号、枠8パーツ、土の平坦部内・岸より上への配置、HUD領域の重なりと入力遮断を検証した。全角度・大きな作物・全エディタ表示の実機確認は未実施。

クリック前に、カーソル下の候補マスを細い水色の四隅で表示する。水色は「クリックすると選ばれる候補」、黄色は「現在選択中」を表す。水色の表示だけでは選択番号・畑データ・道具の結果を変更しない。HUD、操作ボタン、メニュー上では表示せず、一時停止・観察・地形プレビュー・作物選択・目標達成中も無効にする。

ホバー確認済み: Releaseの1280x720と1920x1080で、選択19を維持したまま候補15を水色表示、候補をクリックして黄色選択と番号19へ切替、右側HUD上で候補表示が消えること、農場メニュー中に表示されないことを確認した。全マス・高い作物越し・自由カメラの極端な角度・Debugエディタの実画面は未検証。

1. 畑のマスをクリックし、画面下の道具欄から道具を選ぶ。
2. 右下の「このマスを耕す」「水やりする」「種を植える」「収穫する」をクリックする。押しっぱなしでは連続実行しない。
3. 耕したマスで種が不足すると、クワを持ったままでも「種の購入へ」に切り替わる。農作業・売買画面でカブ／ニンジンを選び、価格と所持金を確認して「1個買って畑へ」。成功すると種の道具で畑へ戻る。「種を植える」は別途押す。従来の「選んだ種を1個買う」は購入後もメニューに残る。
4. 現在の道具が使えず、次に使う道具がある場合は「クワに持ち替え」「じょうろに変更」「種に持ち替え」「収穫道具に変更」を表示する。クリックは持ち替えだけで、次のクリックから作業を実行する。自動で種を消費したり水やりしたりしない。
5. 成長途中・水分満タンなどは理由を表示する。次の道具を案内できない場合は実行を無効にする。選択マスの詳細と次の作業は従来の左下HUDで確認する。今の道具が使える間はその操作を維持し、勝手に持ち替えない。

一時停止中・目標達成後は実行不可。観察中・地形プレビュー中・作物パイメニュー中は通常の実行欄を出さない。無効なボタンや説明欄のクリックも背後の畑へ渡さない。Debug/Developmentの既存ImGui操作は変更しない。

### 農場のカメラ（9/9追加）

- 目標確認の「この農場でプレイする」から、畑を見渡す視点で始める。畑のデータやプレイヤー位置は変えない。
- プレイ画面右の「農場を見渡す」で、土の外周・編集可能な高さ・作物用の余白をHUDの空き領域へ収める。「プレイヤーを追う」で従来の追従視点へ戻る。
- 見渡す状態でもマスをクリックして選び、右下の実行ボタンで農作業できる。カメラ切替のクリックは農作業へ流さない。

### マス境界とクリック（9/9追補）

- 上記の境界・短いクリックの課題に対し、未耕作の通常マスに細い内枠メッシュを追加した。枠を目安にマスをクリックし、明るい選択枠と左下の番号を確認する。実際の選択範囲は従来のマス全体で、内枠は目印。耕すと内枠は消え、既存の畝表示になる。
- マス間の坂と水路の接続形状は変更していない。内枠は平らな植付け面の内側にあり、用水路・水源へは出さない。ImGui・デバッグラインではなく既存OBJの描画で、Debug/Development/Releaseに共通。
- マウスボタンは押す／離す履歴を取得し、フレーム間に完結した短いクリックも検出する。一フレーム内の複数クリックは一回にまとめ、メニューを閉じた後の別操作へ連打を持ち越さない。
- 他ウィンドウから戻ったときの古いクリックは破棄する。戻った瞬間に押されていたボタンは、一度離してから押し直す。入力バッファがあふれた場合も、不完全な履歴で農作業をせず再同期する。
- 実機確認: 1280x720と1920x1080の境界表示、番号19/15/4/12への選択、4番の耕作→購入画面→一個購入（300G→260G、種0→1）→植付け（1→0）、通常のフォーカス復帰。今回の操作に再クリックは不要だった。復帰中の押しっぱなし保護・短い押下／解放はCPUテストでも確認。
- 未検証: 実デバイスでのバッファあふれ、押したままのウィンドウ切替、マウス全機種、長時間高負荷、Debugの全操作。バッファ設定に失敗した環境では従来方式へフォールバックし、デバッガへ通知するため、短いクリックの改善は適用されない。クリック位置は従来どおりフレーム時点のカーソル位置であり、複数地点のクリック履歴を再生する機能ではない。

## 用水路を連続配置する

1. 開始マスを選ぶ。
2. 地形・用水路から「用水路をつなげる」を選ぶ。
3. 地面上を左ボタンでドラッグする。既存の経路プレビューで変更候補を確認する。
4. 「この変更を確定」を押す。やめる場合はキャンセルする。

撤去も「用水路をまとめて撤去」から同様に操作する。古い世代の畑に対する確定や、Systemが禁止する配置は実行しない。プレビュー中は実際の畑へ書き込まない。

## 記録・観察・撮影

- セーブ・ロード: 上書き保存／名前を入力して新規保存、前後の記録選択、名前付き一覧から読込。現在・選択中の保存名をゲーム内に表示する。既存の名前変更・削除はReleaseメニューの対象外。
- 配置だけを保存・再現: 進行セーブとは独立した[配置ライブラリ](FarmLayoutPresets.md)。高さ・耕した区画・用水路・水源を記録する。適用すると植わっている作物は消えるため確認が必要。
- 読込・最初から・終了: 未保存変更を失うため確認画面を挟む。読込後は古い比較記録とタイムラインをリセットする。
- 観察ノート: 選択マスをA/Bに登録し、同じ作物・高さ・成長度など既存Systemの比較条件を満たしてから開始。成熟・水分・地形の行と養分充足度の行、品質点、予想単価、水分・成長を表示する。
- 時間・カメラ: 停止／再開、1倍／2倍／4倍、プレイヤー追従／農場を見渡す。
- 録画例: 通常速度で種購入→作物選択→耕作・植付け→地形と用水路のプレビュー・確定→生育比較→収穫・販売。編集中のメニュー画面と通常のHUD画面を両方含める。

### 育成中の水分履歴と品質（9/10追加）

- 作物が成長している間、乾燥・水不足・適量・水過多だった時間と、その期間の成長効率を畑マスごとに記録する。単に収穫直前だけ水分を整えても、長く続いた悪条件は消えない。
- 収穫時の品質点に含まれる「水分バランス」は、履歴がある場合は育成期間の平均成長効率から計算する。農場メニューの観察ノートで4項目の品質評価・品質点・予想売価を確認でき、収穫時は通常HUDの品質点と価格へ反映される。
- Debug/Developmentでは畑Inspectorの「育成中の水分履歴」に、記録秒、4状態の割合、期間平均の成長効率を表示する。ここは確認表示だけで、ImGuiから履歴を書き換えない。
- 履歴は進行セーブ、Load、Undo/Redo、Timelineに含まれる。旧Save Version 1～5は履歴なしで読み込み、以後に時間を進めた分から記録する。植付けで初期化し、収穫後は次の作物へ持ち越さない。
- 作物サイズ・巨大化率・大会点は未実装。品質レーダーは下記の養分充足度を加えた4項目。

### 土づくり・養分（9/10追加）

- 畑を選んで耕し、「農場メニュー → 農作業・売買 → 土づくり・養分を確認」へ進む。植付け前は選択中の種、植付け後はそのマスの作物を表示する。
- 「堆肥を混ぜる（無料）」で養分を100に補う。植付け前の耕作済み土だけで使える。満タン・作物あり・水路・水源では実行不可。現在は無料の試作ルールで、肥料購入や費用は未実装。
- カブの目安45・成長0～100%の消費30、ニンジンの目安65・消費45。ゲーム用の抽象値で、実在の栄養素量ではない。初期養分60。目安以上では不足なし、成長で消費するため事前準備に意味がある。過剰養分のペナルティはない。
- 養分不足は品質と売価に作用し、成長速度は既存の水分条件で決まる。収穫後も土の残量を維持する。次の植付け前に再び補える。
- Debug Inspectorに4軸レーダー・数値・堆肥ボタン、Releaseの土づくりと観察ノートに養分評価を表示。メニュー中は既存の時間停止を維持。堆肥はUndo/Redo対応。
- 通常セーブschema7に養分と履歴を保存。配置だけの保存には含めない。schema1～6は初期養分60・養分履歴なしとして移行。旧収穫済み作物の点数・価格は維持し、生育中で養分履歴がない場合は現在の養分を暫定評価に使う。

## 畑を見ながら観察する（追加）

従来の観察ノートはそのまま使用できる。追加パネルはReleaseのSprite UIであり、ImGuiではない。Debug/Developmentの既存観察UIは変更していない。

1. 畑でマスを選び、農場メニュー → 観察ノート → 「選択マスを観察Ａに登録」。Ｂからでも開始できる。
2. メニューが閉じ、観察専用パネルを表示して時間を止める。もう片方が未登録ならその選択待ちになる。畑をクリックすると直接登録する。方向キーで選び、Enterでも登録できる。
3. Ａ／Ｂ両方を登録したら、比較条件を確認して「生育比較を開始」。時間が進み、水分・成長・計測時間を同じ画面で確認できる。
4. 「時間を止める／進める」と1・2・4倍速を利用する。停止中でも選択・登録は可能。「Ａ／Ｂのマスを選択」は登録を変えず選択枠だけを移す。
5. 「比較を終了」で結果を保持し、観察中の時間も停止する。両方が収穫可能になった場合や計測が無効になった場合も、観察画面では自動停止する。
6. 「農作業に戻る」で通常HUDと操作へ戻る。時間停止設定は観察に入る前の状態へ戻す。比較そのものの終了は「比較を終了」で行う。

- 「Ａ／Ｂを選び直す」で再び畑から登録できる。選択待ちだけの取消はキャンセル・右クリック・Esc。登録済みの記録は取り消さない。
- Ａ／Ｂは観察枠の名前であり、キーボードのA/Bではない。観察中のWASD移動・B購入・道具操作は遮断し、選択操作で農場を変えない。
- 「収穫秒」は比較開始から収穫可能に到達したゲーム内経過秒。残り時間の予測ではない。未到達は `--`。2倍速なら実時間より2倍速く計測秒が進む。
- 終了後の水分・成長・収穫秒は計測終了時の記録。無効表示の場合は正しい比較として扱わず、リセットして登録し直す。
- 比較には異なる2マス、成長途中の同じ作物、同じ高さと成長度などが必要。時間停止は既存の成長差を揃える機能ではない。差があれば同時期に植えたマスを用意する。
- 観察中は通常HUDを一時的に隠し、パネルの重複を避ける。観察ノートボタンから従来の品質詳細に戻れる。農作業・地形・記録タブへ移動すると観察専用操作を抜ける。
- ユーザー提供の16:05:24画像では、Ａ登録後のプレイ画面、Ｂ選択待ち、一時停止、Ａの水分・成長表示を確認した。下端のボタンが画面端に寄っていたため16px上へ調整。「農場を見渡す」は観察パネルを避ける専用の距離・位置へ調整した。修正後の実機操作、比較開始から完了までの通し確認は未完了。CPUテストと実操作確認は区別する。
