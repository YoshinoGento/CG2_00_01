# プレイ画面の給水切替（2026-09-24）

## 実装

通常の農作業画面にある水分案内の右へ「給水 切／入」を追加。既存の給水状態行を押して地形操作へ移る経路も維持した。パネルの位置・サイズは変更せず、2行目を助言486px・隙間12px・操作130pxに分けた。日本語ラベルの追加や画像の再生成は不要。

- `FarmGrowthSystem.h`: 既存助言から過湿を問い合わせる`FarmWaterGuidance::HasExcessMoisture`。水分の閾値・成長式は変更しない。
- `FarmTerrainView.h`: 給水の明示的な入/切要求と、助言の警告フラグを生成する。Viewはマスを変更しない。
- `FarmRuntimeController.cpp`: 既存Systemから選択マスの操作可否を渡す。実行は既存`SetIrrigation`経路を再利用する。
- `FarmRuntimeUI.h/.cpp`: Itemに警告表示を追加。暗い背景に橙色の文字。色だけでなく「水過多」の文言でも伝える。
- `FarmControllerWindow.cpp`: ImGuiの助言も同じ判定で警告色にする。従来のチェックボックスを維持する。

閉じても土・水路の残留水は消さず、手動のじょうろは禁止しない。収穫可能時は既存の収穫案内を優先する。不明・無効な状態を水過多として表示しない。自動で給水を切る機能ではない。

## 検証結果

- `run_farm_runtime_view_test.cmd`: 合格。可視/閉/操作可否/給水状態/全助言の組合せ、要求値0/1、無効ボタンと隙間のクリック、HUDとの非重複、20px相当以上の横幅を検査。既存162カメラ条件・フォーカス・容量・atlas範囲も合格。
- `run_farm_water_guidance_test.cmd`: 合格。4作物・4倍率・給水開閉・5給水状態・5水分条件の800ケース、収穫優先などのガードを検査。
- `run_farm_irrigation_intake_test.cmd`: 合格。給水保存則、閉時の供給停止、手動給水、履歴、古いプレビューと観察比較の扱いを確認。
- Debug/Release x64 Build: 両方成功。ログは`generated/codex_checks/intake_hud_debug.log`と`intake_hud_release.log`。
- 分離したRelease・1280×720: 過湿のトマトで警告文を表示。プレイ画面から給水切→入が成功し、停止中のマス#1/水分80%/成長27%を保持。メニューへ移らず、クリックで別のマスや農具を選ばない。
- 残り水を持つ隣接用水路の別fixture: 「残り水で給水可能」と「水過多：自動給水を切る」を表示し、給水切ボタンを強調。押すと「この畑の自動給水：切」と「追加の水やりを控える」に変わり、土の水分が即座に消えないことを確認。
- 最大化1920×1008: 通常プレイ画面の助言とボタンは重ならず収まった。

分離先は`generated/codex_checks/intake_hud_20260924`。合成した検証用セーブだけを利用し、元のproject/Settingsは変更していない。検証用ゲームは終了済み。これは週次報告用の成果動画ではない。

## 制約と監査

最大化操作の際に意図せず地形操作画面へ移った。以前にも記録されたウィンドウ操作とゲーム入力の干渉が疑われるが、原因は今回未特定・未修正。農場へ戻って最大化時の表示を確認した。実機でのCtrl+Zは結果を確認できていないため、Undo／Redoは専用Systemテストの証拠と区別する。

ImGuiの実機表示、他DPI、ゲームパッド、全作物の実機比較、保存再起動、GPU性能は今回未検証。水不足時の再開を促す専用案内や自動給水制御は追加していない。

追加の通常プレイ描画は既存pool内のボタン背景1枚＋ラベル1枚。新しいTexture/Descriptor/Buffer、Barrier/Fence、所有権の変更はない。Itemにboolを1個追加しただけで、毎フレームの新規動的確保経路は追加していない。既存の文字列・Undoコマンドの確保は維持する。容量ガードを通し、警告フラグはAdd成功時だけ設定する。nullableな選択とマス範囲は既存Systemで検査し、UIに生ポインタを保存しない。
