# 正式3作物への移行・検証記録

## 目的と実装範囲

初期案のニンジン・トマト・かぼちゃを、試作のカブと混同しない。正式3作物の外観、購入、方向選択、成長、水分・養分、品質・サイズ、収穫・販売・大会記録、保存まで対応した。数値は暫定のゲームバランスで、実農業や栄養成分の再現ではない。

- `FarmTypes`：保存IDを維持し、Tomato/Pumpkinを末尾追加。所持数配列は旧カブを含む4枠、プレイヤーの新規選択は3種類に分離。
- `FarmRules`、Growth/Soil/Quality/Size/Economy Systems：作物別データと計算。生育の期間平均を品質・サイズに使う。既存の取水停止、手動給水、土壌養分、堆肥、Undo/Redoへ接続。UI自身に栽培・売買の状態変更を持たせない。
- `FarmDocumentSystem`：schema16。schema1～15の2枠を4枠へ拡張し、新しい枠は0。旧カブとニンジンは変換しない。未知ID、配列長不一致、範囲外整数、旧schemaへの新作物混入は拒否。ロード検証完了前に本体へ適用しない。
- `FarmSeedShopSystem/View`：正式3作物、2商品ずつのページ、前後移動、購入確認。新規選択の既定はニンジン。C方向選択は左ニンジン、右トマト、下かぼちゃ、上・中央は変更なし。
- `FarmHUD`、Quality/HarvestDisplay/Runtime UI、EditorLocalization：日本語名・種数・購入通知・レーダー・展示物の対応。Releaseには「土・養分・適正水分」で作物ごとの適正範囲を表示。ImGuiの既存Inspectorの予測範囲・効率・履歴・養分・レーダーは共通Systemを参照。
- `FarmMeshLayout/Renderer`、mesh生成器：新2作物に専用の実・茎/つるモデル4個。苗と成熟で見た目を切替。かぼちゃの丸みと茎を修正。収穫時は果菜の実だけを表示し、根菜は葉付きで引き抜く。
- 画像：正式2作物の種袋・収穫物atlasをimagegenで生成。旧画像はカブとニンジンの互換表示へ維持。最終HD-2D素材・町の店舗が完成したという意味ではない。

## 性能・安全性と残課題

Crop/index/配列長・整数範囲・NaN・null・履歴ID/世代を既存ガードと追加テストで確認。作物判定は定数時間、更新全体は従来のO(マス数)。成熟作物は最大2パーツ、果菜の収穫演出は1パーツでDrawCall上限を増やさない。共有モデル4個と画像atlas2枚、HUD追加Spriteの初期化時資源は増える。展示枠別Spriteで同一作物2件のConstant Buffer上書きを防ぐ。Fence/Barrier/Descriptor所有権は変更していない。VRAM/CPU-GPU時間の実測・大農場の負荷検証は未実施。

価格・成長秒数・水分範囲はFarmRules、土壌養分はFarmSoilSystemのconstexpr。30日バランス・作物解放日・2×2かぼちゃ・トマトの連続収穫は未確定/未実装。現在は全3種類を買え、1回収穫すると耕した土に戻る。新schema16のセーブは旧EXE非対応。旧版と往復する際は旧記録を残して別名保存する。

既存の未コミット変更は維持。個人就職作品ブランチとHEADを変更せず、stage/commit/push/merge/GitHub操作は行わない。
