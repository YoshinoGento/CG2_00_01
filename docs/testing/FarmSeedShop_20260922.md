# 種屋の実物選択プロトタイプ 検証記録

同日追記: 写実的すぎるというユーザー指摘を受け、種袋の作物を展示画像と同じドット調へ差し替えた。以下の初回素材出自は履歴として保持する。現行素材と調査・検証は [HD-2Dアート方針](../design/FarmHD2DArtDirection_20260922.md) を参照。

## 同日追加: 種袋の見た目を修正

- ユーザーの指摘を受け、つぶれた作物メッシュの模様を撤去。専用の印刷画像`project/Resources/ui/farm_seed_packets.png`を追加。カブは白い球状の根、ニンジンは細長い橙色の根と葉を描き、大きく「カブ」「ニンジン」と表示する。
- 内蔵image_genで作成した独自・無ブランドの画像。1536x1024を左右768x1024に分け、各180x240のNative Spriteへ等比表示する。3Dの台・背景に合わせた固定視点の2.5D表示であり、回り込める3D袋ではない。
- 商品の当たり判定を袋全体まで拡張。専用テストに縦横比・画像全体の判定内包含・影と商品名の非重複を追加し合格。Debug／Release x64の再ビルド成功。
- コピーしたSettingsを使ったReleaseで1280x720・最大化の両表示を確認。ニンジン袋の右下の端をクリックして選択・持ち上がり・商品情報更新を確認。購入ロジックは無変更で、自動の購入・取消・二重確定テストも再合格。今回の修正後は実画面での購入確定を再実施していない。
- RendererのObject3dは21から9へ削減。Spriteを2つ、既存poolから影を2枚追加し、TextureManager管理のatlasを1枚追加。ベースRGBAは6MiB、mipを含む実際のVRAMとGPU時間は未計測。初期化時にロードし、毎フレームのGPUリソース生成は行わない。以下の21オブジェクト記述は修正前の検証履歴。

生成プロンプトの仕様: 市販の日本語の野菜種袋の正面印刷を左右2商品で構成。左は深緑の見出しと白いカブ、右は朱色の見出しと橙色の細長いニンジン。大きな商品名、上向きの緑の葉、白い紙、細い枠を用いる。文字は「野菜の種」「カブ」「ニンジン」「たね」のみ。価格・ブランド・宣伝文句・遠近感・背景は画像に含めず、各袋の半分を独立使用できる構成。画像の生成には内蔵ツールを使用し、CLI/APIは使用していない。

## 対象

2026-09-22。Releaseの種購入に、店台上の種袋を直接選ぶ表示を追加した。農場内を歩いて入店する実装ではなく、独立した固定カメラによる買い物画面の試作。素材は既存の仮メッシュであり、完成版HD-2D表現ではない。

畑・地形操作、既存ImGui、Bキーの即時購入は維持。大会出品・販売画面は今回変更していない。

## 操作

1. Releaseのプレイ画面右側、または農作業・売買メニューの「種屋」を選ぶ。
2. カブ・ニンジンの種袋をクリックする。選択中の商品は台の色と袋の位置で区別する。
3. ＋／－で購入数を1～99個に変更する。所持数、単価、合計、所持金を確認する。
4. 「購入内容を確認」から購入を確定する。確認中のキャンセルではお金・種は変化しない。
5. 「農場に戻る」で元の農場画面へ戻る。買い物中は農場のシミュレーションと入力を停止する。

左右キーの商品選択、上下キーの数量変更、Enterの確認・購入、Esc／右クリックの取消・退出も実装。キーボード経路の実画面検証は未完了。ゲームパッドは未対応。

## 責務

- `FarmSeedShopSystem`: 選択・数量・確認見積もりの状態管理。確定時に見積もりを再検証し、既存`FarmEconomySystem::BuySeed`へ購入処理を委譲する。
- `FarmSeedShopView`／`FarmRuntimeUI`: 読み取り専用の表示投影と入力通知。UIで所持金・在庫を変更しない。
- `FarmRuntimeController`: 画面状態と入力の排他、購入結果の通知・未保存管理を調整する。
- `FarmSeedShopRenderer`: 専用カメラと固定21個の描画オブジェクト。農場カメラを変更しない。
- `GamePlayScene`: 初期化と描画先の切り替えのみ。

## 自動検証

- `tools/tests/run_farm_seed_shop_test.cmd`: /O2 /DNDEBUG /W4 /WXで合格。閉店中・不正選択・数量上限、選択や取消による非変更、確認中の変更拒否、正常購入、二重確定、外部変更で古くなった見積もりの拒否、資金不足、金額・在庫の整数上限を確認。

- 最終Debug x64／Release x64ビルド成功。Visual StudioプロジェクトとfiltersのXML解析成功。

## 実画面で確認した結果

元のSettingsをコピーした`generated/codex_checks/seed_shop_20260922`でReleaseを起動し、元のセーブへの書き込みを避けた。

- プレイ画面から入店し、種袋のクリックで選択商品・所持数・単価が切り替わった。
- 所持金20Gでは購入を確定できないことを確認。
- 検証用農場の既存在庫を売却して461Gとし、ニンジン2個・合計120Gを表示した。
- 購入確認とその取消では461G・種0個を維持。改めて確定すると341G・種2個になった。
- 戻った農場で選択種がニンジン・所持数2個となり、選択マスと農場の視点が維持された。閲覧だけの退出では植付け用の選択種は変化しなかった。
- 最終の袋位置・＋／－配置調整後も通常1280x720クライアントと最大化画面で確認。最大化後も袋のクリック対象と商品切り替えが一致した。確認した表示に文字の重なり・見切れは見られなかった。

買い物中は一時停止表示と日付の維持を確認したが、内部経過秒の計測はしていない。これは操作確認記録であり、週次報告用動画の代わりではない。

## 実行時安全性と負荷

- 購入処理は確定状態から1回だけ実行する。価格・所持金・所持数・数量の一致を確定直前に確認し、古い見積もりを拒否する。
- ModelManager所有のメッシュを参照し、描画用Object3dとCameraはRendererが保持する。初期化時に必要ファイル・モデル・白テクスチャを確認する。
- Rendererは固定21オブジェクトを初期化時に用意する。毎フレームのGPUリソース生成を追加しない。店表示中は農場描画を置き換える。
- ラベルatlasは306項目、2560x3516。以前の2560x3296からベースRGBA換算で約2.15MiB増加。テクスチャ数・Descriptor・Barrier・Fenceの管理方式は既存のまま。
- GPU計測・Validation Layerによる追加検証は未実施。固定オブジェクト数は実測DrawCallやGPU時間の保証ではない。
