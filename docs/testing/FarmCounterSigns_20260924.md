# 種屋・展示台の札 2026-09-24

## 変更

- FarmSeedShopView / FarmHarvestDisplayView: 品名・価格・品質の文字を常に濃色に統一。SelectionTargetで袋・作物から札までを同じ選択対象にする。
- SeedShopLayout: SignBoardとSelectionTargetの境界を共有し、不正indexは空の矩形を返す。札の下端542、footer開始544で分離する。
- FarmSeedShopRenderer: 共通のunit_boxで枠・札面・留め具を描画。文字と同じ投影から前面位置を計算し、台の前縁より手前に置く。選択中は黄色の枠。
- UIは入力通知のみ。経済計算、保護、出品予約、セーブ、Sceneの責務は変更しない。

## 検証

- seed-shop / harvest-display専用テスト: 合格。札のクリックと対応ID・generation、確認中の選択固定、文字色、境界、空き枠、既存の購入・二重確定・stale検証を含む。
- Debug / Release x64: ビルド成功。
- 元のSettingsとは別の合成データを用いたRelease: 1280x720と最大化1920x1008で札の文字・枠・背景に見切れなし。
- 種屋: 価格札からニンジン、品名札からカブへ選択可能。確認中にカブの札を押してもニンジンの見積もりを維持。キャンセル後の所持金300G・種0個は維持。
- 展示台: 品質札からニンジン記録#2へ切替、収穫日が対応。2ページ目はカブ#3と空き札。空き札を押しても選択・取り置きは変更なし。
- この合成データの画面確認は週次報告用の実績動画ではない。

## 安全性・制約

- 固定Object3d数は9から17へ増加し、店画面で8 DrawCall増加。共有mesh/textureを再利用し、描画ループに動的確保を追加しない。初期化時のObject3d定数バッファ数は増える。
- 既存のModelManager所有権・nullptr検査・固定配列の範囲検査を維持。Descriptor / Barrier / Fenceの設計変更なし。GPU負荷とVRAMは未計測。
