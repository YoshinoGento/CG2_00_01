# フリー農業モード / 2026-09-28

## 変更範囲

- FarmProgressionSystem: FreeFarming、終了条件の抑制、種各5個の初期ルール。不正enumとFree+clearedのSnapshotを拒否。
- FarmContestDaySystem: フリーでは日付を進め、大会日の自動案内と終了日クランプを適用しない。既存モードの既定動作は維持。
- FarmDocumentSystem: schema17でモードを保存。旧1-16の読み込みを維持し、新モードを旧形式で渡された場合は変更前に拒否。
- GamePlayScene: モードを各Systemへ渡す、Reset時のルール取得、HUD用状態の構築のみ。UIへゲームルールを移していない。
- FarmPlayFlowView／RuntimeController／HUD／ImGui: フリー表示と既存コマンドへの切替通知。金額目標の表示はフリーで隠す。
- WinApp/main: タイトル「水道農業」、起動失敗ダイアログのSuidoNogyo表記。

FarmTimeAdvanceSystemは未接続の基盤。フリーでは新しい大会日スキップの開始対象がない。今回もScene/UIへの接続は行っていない。

## 実機確認

ZIPから展開した検証用Releaseを、別の作業ディレクトリからStartGame.cmdで起動。1280x720クライアント表示で以下を確認。

- ウィンドウ名「水道農業」、開始画面「フリー農業モード」と終了条件なしの説明に見切れなし。
- 初期Day1・300G・ニンジン種5。HUDの540G進捗バーはなく、フリー表示に置換。
- 保存一覧は1/1、保存名「フリー農業 種各5個」を表示。
- 畑#0を耕す → 保存 → 終了 → 再起動でフリーと耕し済み#0を復元。
- 時間・カメラの3モード表示。フリー → 大会 → フリーで日付2・300G・種5・耕し済み#0を保持。
- やり直しでフリーのまま日付1・300G・種5・未耕作へ戻る。全3作物の個数は自動テストでも確認。
- 独立した合成fixtureのDay32・1000Gで開始でき、耕す操作も成功。2倍速でDay35まで進み、終了画面や大会日の停止がない。これは境界検証であり、30日間の通しプレイや週間報告の動画実績ではない。

## 安全性と未検証

新規の所有権・Descriptor・Barrier・Fenceは導入せず、既存Spriteプールと日本語アトラスを利用。アトラス拡張分の常駐テクスチャ量は増えるが、新たな毎フレーム確保経路は追加していない。UI範囲・不正enum・保存形式・int境界を検証。既存Sceneの規模やDX12全体の正当性を認定するレビューではない。

長期間連続プレイ、全DPI/GPU、別PC、ImGuiの実機表示、ライセンス監査は未検証。将来、TimeAdvance基盤をUI接続する際はロード・モード変更・リセット時のセッション無効化も確認する。フリーの大会は既存10/20/30日限定で、以後の繰り返し開催は未実装。
