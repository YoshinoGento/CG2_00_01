# 生育比較の操作・撮影手順

## 目的

同じ作物を植えた2マスの水分と成長の変化を実測する。Inspectorの予測値だけでなく、実際に進んだ成長度と収穫可能になった時刻を確認するための開発用機能。

## 準備

1. 開発モードで、同じ作物の種を2個用意する。必要なら先に購入する。
2. 上部ツールバーでゲームを一時停止する。
3. 高さが同じ2マスを耕して、同じ作物を植える。停止中に植え、両方の成長度をそろえる。
4. Inspectorから水やりを実行し、例としてカブのAを水分50%、Bを100%にする。自動給水のない場所を使うと条件を追いやすい。水やりは既存の通常操作で行い、測定機能は水分を設定しない。
5. 畑Inspectorの「生育比較」を開く。Aのマスを選んで「選択マスをAに」、Bを選んで「選択マスをBに」を押す。
6. 作物・高さ・開始成長度を確認し、比較欄の `>`（比較開始）を押してから、上部ツールバーで再生する。

開始できない場合は比較欄に理由が出る。別のマス、育成中の同じ作物、同じ高さ、成長度差0.01ポイント以内が必要。植え付け前・収穫可能・用水路・水源は対象外。

## 表の読み方

- 開始水分／現在水分：給水と乾燥を含む実際の水分。
- 開始成長度／現在成長度：同じ開始条件からどこまで進んだか。
- 増加ポイント：現在成長度から開始成長度を引いた値。倍率ではない。
- 生育時間：成長処理が進んだシミュレーション秒。1倍・2倍・4倍を反映し、実時間とは区別する。
- 収穫可能まで：開始から、収穫可能と初めて観測した更新までの秒数。予測時間ではなく、未到達は `--`。

`||` は測定停止、`X` は登録・結果の解除。両方が収穫可能になると自動終了し結果を保持する。停止後の表は記録した結果で、現在の畑を更新表示し続けるものではない。

## 測定中の注意

- 測定中は対象マスへの水やり、収穫、高さ変更、Undo/Redo、Loadをしない。対象マス変更またはGrid世代変更を検出すると結果を無効化する。
- 対象外の用水路・水源等の変更をすべて検出するわけではない。農場全体を編集せずに観測する。
- 一時停止・灌漑プレビュー中は測定時間も停止する。Clear時も測定を停止する。
- 自動給水と乾燥があるため、最初の水分だけで最後まで一定の速度差になるとは限らない。
- 結果はセーブされない。比較表の表示だけで週間報告の成果が実証されるわけではない。

## 撮影

ゲーム全体が分かるプレイ動画の中で、開始条件、比較開始、一定時間後の水分と成長度、収穫可能になる結果を映す。比較後は収穫・販売まで通常プレイを見せる。開始時と結果時のA/Bのマス番号を同じ画面で読めるようにする。

水分の減少や自動給水も説明し、見えた変化だけを実績として記載する。点数をあらかじめ保証する機能ではない。

## 検証範囲

実Systemを使ったCPUテストと実ImGuiの入力・幅・言語切替テストを用意。これらは実機で植え付けから比較完了まで操作した動画の代用ではなく、実機の通し確認は別途必要。
