農業ゲーム（制作中） ReadMe

■ 実行方法
「01_実行ファイル」フォルダ内の CG2_00_01.exe を起動してください。
Resources、Settings、DLL、csoを別の場所へ移動しないでください。

■ 主な操作
矢印キー：畑の選択
1 / 2 / 3 / 4：HOE / WATER / SEED / HARVESTを直接選択
Q / E：道具を前後へ切り替え
Enter：選択中の畑へ道具を使用
T：時間倍率を1倍・2倍・4倍で切り替え
Y：1日進める
W / A / S / D：プレイヤー移動
Space：ジャンプ
Shift：低速移動
F1：プレイヤーカメラとデバッグカメラを切り替え
マウス左クリック：畑を選択
Shift＋マウス左クリック：選択と同時に現在の道具を使用

■ 農作業の基本順序
1. Emptyの畑をHOEで耕す
2. WATERで水分を補給する
3. SEEDで種をまく
4. 時間経過で成長率が100%になるまで待つ
5. HARVESTで収穫する

■ 動画とRelease版の表示差
作品紹介動画はDevelopment版で収録しているため、開発用ImGuiウィンドウが表示されています。
提出したRelease版はゲーム画面のみで、開発用ウィンドウは表示されません。
