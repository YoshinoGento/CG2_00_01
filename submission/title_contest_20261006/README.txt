水路農業 / タイトルシーンコンテスト提出用
Release x64 / 2026-10-06

【起動】
ZIPをすべて展開し、StartGame.cmd または SuiroNogyo.exe を開いてください。
EXEとResources、DLLを別々の場所へ移動しないでください。
Windows 10/11 x64、DirectX 12対応GPUが必要です。
インターネット接続は不要です。終了はウィンドウの閉じるボタンからできます。

【タイトル】
朝・昼・夕・夜が循環し、畑の成長、雲、水面、文字の波紋が動きます。
「はじめる」をクリック、Space、Enter、またはゲームパッドのAで開始します。
右上の音設定から環境音と水音を個別に調整できます。
音量は初期値40%。変更はこのフォルダーのSettingsに保存されます。

【ゲーム】
最初の案内を進めると農場へ移動します。
初期記録はフリー農業モード、1日目、300G、ニンジン・トマト・カボチャの種を各5個です。
所持金や日数による強制終了はありません。
1〜4: 農具選択 / Enter: 使用 / Q・E: 農具切替 / C: 作物切替
畑のマスはクリックで選択できます。画面のボタンからも各操作ができます。
保存は農場メニューから行います。他の開発用セーブは同梱していません。
