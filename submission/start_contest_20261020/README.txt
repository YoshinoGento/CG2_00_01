水路農業 / スタート演出コンテスト提出用
Release x64 / 2026-10-20

【起動】
ZIPをすべて展開し、StartGame.cmd または SuiroNogyo.exe を開いてください。
EXE、Resources、DLLを別々の場所に移動しないでください。
Windows 10/11 x64、DirectX 12対応GPUが必要です。ネット接続は不要です。

【今回の演出を見る手順】
1. タイトルの池をクリックするか、Space / Enter / ゲームパッドAを押します。
2. 農場の案内画面で「この農場でプレイする」をクリックします。
3. 草の露、水滴、土、草原、農場、道具と種を見せる約14秒の開始演出が流れます。
4. 演出後に操作用のHUDが現れ、農作業を開始できます。
演出中の「スキップ」またはSpace / Enter / Escで演出を短縮できます。
初期記録はフリー農業モード、1日目、300G、種3種類を各5個です。
開発中のセーブや以前のプレイ記録は同梱していません。

【もう一度見る】
未プレイの同梱状態なら、ゲームを終了して再起動すると再度見られます。
プレイ後は農場メニューから「タイトルへ戻る」を選び、案内画面の
「農場を最初からやり直す」で初期化してからプレイしてください。
保存済み農場では、水源や用水路などの状況に応じた導入になります。

【操作・音量】
農具は下部アイコンまたは1〜4、畑のマスはクリックで選択します。
農場メニューから保存やタイトルへの復帰ができます。
タイトル右上の音設定で環境音・水音を調整できます。
終了はウィンドウの閉じるボタンから行えます。

【同梱範囲・確認上の注意】
実行に必要なファイルと初期セーブのみです。動画は別ファイルです。
ソースコード、デバッグ情報、制作途中の画像や動画は含めていません。
読み込み中に短い引っ掛かりが残ることがあります。別PCでの動作は未確認です。
