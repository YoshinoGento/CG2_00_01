水道農業 / 提出物の案内

【ゲームを遊ぶ】
このフォルダーの StartGame.cmd を実行してください。
SuidoNogyo.exe、Resources、Settings、DLLは移動・分離しないでください。
初期セーブは1件のみ。1日目、300G、ニンジン・トマト・かぼちゃの種が各5個です。
詳しい操作は README.txt、素材・依存ライブラリは CREDITS.txt と Licenses を参照してください。

【ソースコード】
Source/project/CG2_00_01.sln に実行版04と対応するゲームのソースを収めています。
提出用ソースの対応構成は Release / x64 のみです。
Visual Studio 2026（v145）、C++デスクトップ開発、Windows SDK 10が必要です。
ライブラリは同梱したAssimp 5.3.0 / zlibとDirectXTexを使用します。
DXC DLLのコピー先・参照元は、この提出物内の相対パスに変更しています。
Debug/Developmentは学校配布素材を参照するため、提出用の構成から除いています。
ゲームのC++処理、シェーダー、配布用Resourcesは変更していません。
ビルド後は Source/RunBuilt.cmd から起動できます。
元の開発セーブや録画用セーブ、.git/.vs/PDB/ビルド中間ファイルは同梱していません。

作物は通常画面のCキー、または種屋で購入した作物の選択から切り替えてください。

大会の順位・賞金、最終HD-2D表現などは開発中です。
