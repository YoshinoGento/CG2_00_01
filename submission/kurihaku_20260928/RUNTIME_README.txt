3D農業サンドボックス（仮称） / Release実行版
作成日: 2026-09-28

【起動】
1. ZIPの場合は「すべて展開」でフォルダー全体を展開してください。
2. FarmGame_Runtime 内の StartGame.cmd をダブルクリックしてください。
3. 初回は新しい農場です。開発者のセーブデータは含まれていません。

EXEだけを移動せず、Resources・dxcompiler.dll・dxil.dllを同じ場所に保ってください。
書き込み可能な場所へ展開してください。初回のシェーダー生成に時間がかかる場合があります。
Windows x64 / DirectX 12対応環境が必要です。最低GPU性能と別PCでの動作保証は未確定です。

【まず試す操作】
・時間を止める／進める: 画面上部のボタン。
・全体を見る: 「農場を見渡す」。
・種の購入: 「種屋」で種袋を選び、数量→確認→購入。
・畑をクリックして選び、クワで耕す→種を植える→水分を管理→収穫。
・農具: 1～4、または画面下のボタン。Enterで選択マスに使用。
・作物選択: C。ニンジン・トマト・かぼちゃを選べます。
・地形と水路: 「地形・用水路」で編集し、プレビュー後に確定／取消。
・水が多すぎる場合は自動給水を切り、追加の水やりを控えます。
・収穫物は展示台から品質・大きさ・保護・出品予約を確認できます。
・10／20／30日目の大会に1個ずつ出品。30日目の提出または31日目で最終結果。

【保存・終了】
農場メニュー→セーブ・ロードで進行を保存します。自動保存ではありません。
配置専用保存は地形配置を記録する別機能で、進行全体の保存ではありません。
保存先: この実行版フォルダー内の Settings/farm。
終了はゲームウィンドウ右上の閉じるボタンです。

【同梱物】
CG2_00_01.exe: ゲーム本体
dxcompiler.dll / dxil.dll: 実行時シェーダーコンパイル関連
Resources: モデル・画像・シェーダー・日本語フォント等
StartGame.cmd: 作業フォルダーを合わせる起動用スクリプト
Licenses: 現在収集できているライセンス文書
NOTICES_PENDING.txt: 外部提出前に残っている権利・制作範囲の確認事項
