3D農業サンドボックス（仮称） / 企業向け体験用
2026-09-28

【起動】
ZIPを新しいフォルダーへ「すべて展開」して、StartGame.cmd を実行してください。
以前の実行版フォルダーへ上書き展開すると古いセーブが残るため、別フォルダーへ展開してください。
最初の画面で「この農場でプレイする」を選びます。

【試遊の初期状態】
保存名: 企業向け体験用 種各5個
1日目 / 所持金300G / 未耕作の5×4マス
ニンジンの種5個、トマトの種5個、かぼちゃの種5個
種は購入せずに植え始められます。足りなくなった種は種屋で買えます。
所持金によるクリア条件はありません。540Gを超えても試遊を続けられます。
10・20・30日目の大会はあります。30日目の提出または31日目に最終結果へ進みます。
完全な日数無制限フリーモードではありません。

【まず試す】
1. 「農場を見渡す」で全体を見る。必要なら「時間を止める」で準備する。
2. 畑マスをクリックして選び、クワで耕す。
3. Cで植える作物を選択。農具を「種」にして選択マスへ使用する。
4. じょうろや用水路で水分を管理し、時間を進める。
5. 収穫可能になったら収穫。展示台で個体の品質・大きさを確認する。
6. 売却する野菜と、大会へ保護・予約して残す野菜を選ぶ。

農具は1～4または下部ボタン、Enterで使用。
「地形・用水路」から高さ・水源・水路を変更し、プレビューで確定／取消。
水過多の場合は自動給水を切り、追加の水やりを控える。残水は即座には消えません。
観察ノートではA/Bの畑を登録して生育を比較できます。

【保存・初期状態への戻し方】
同梱の通常セーブは上記1件のみ。開発用・検証用・過去のセーブは含めていません。
進行を残す場合は「農場メニュー→セーブ・ロード→新しい記録として保存」を使うと、
初期状態のセーブを残せます。自動保存ではありません。
初期状態へ戻すには、セーブ一覧で「企業向け体験用 種各5個」を開いてください。
この初期セーブを上書きした場合は、ZIPを別の新しいフォルダーへ展開し直してください。
「農場を最初からやり直す」は通常の初期化なので、種5個の試遊状態への復帰には使わないでください。
「540Gの体験版モード」へ切り替えると金額クリアが有効になります。本試遊では大会モードのまま遊んでください。
終了はウィンドウ右上の閉じるボタン。保存先はこのフォルダー内の Settings/farm です。

【配布に必要なファイル】
EXE・Resources・dxcompiler.dll・dxil.dll・Settingsを分離せず保持してください。
書き込み可能な場所へ展開してください。Windows x64 / DirectX 12対応環境が必要です。
初回シェーダー生成で待つ場合があります。最低GPU性能と別PC動作は未確定です。
